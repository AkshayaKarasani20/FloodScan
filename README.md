# 🌊 FloodScan

An AI-powered flood detection system that identifies flooded regions from satellite images using a U-Net deep learning model.

---

## 📌 Project Overview

HydroVision is a deep learning application developed to detect flooded areas from satellite imagery. The system predicts flood masks and calculates the percentage of flooded area, helping in disaster monitoring and response.

---

## ✨ Features

- Upload satellite images
- AI-based flood detection
- Flood segmentation mask
- Flood overlay visualization
- Flood percentage calculation
- Flood risk analysis
- User-friendly Streamlit interface

---

## 🛠 Technologies Used

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Streamlit

---

## 📂 Dataset

- Sen1Floods11 Dataset
- Satellite Images
- Flood Segmentation Masks

---

## 🧠 Deep Learning Model

- U-Net Architecture
- Binary Image Segmentation
- Dice Loss + Binary Cross Entropy Loss

---

## 📊 Output

The application displays:

- Original Image
- Predicted Flood Mask
- Flood Overlay
- Flood Coverage Percentage
- Flood Risk Level
- Safety Recommendations
